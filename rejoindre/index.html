Invitation MonMédoc

Quelqu'un vous invite à partager un profil : vous verrez les mêmes traitements et prises.

——————
Ouvrir dans MonMédoc Ouvrir la version web
  1. Installez MonMédoc sur votre iPhone (demandez le lien à la personne qui vous invite).
  2. Connectez-vous avec votre compte Apple.
  3. Touchez à nouveau le lien, ou : Réglages › Profils › Rejoindre avec un code.

Code valable 7 jours, une seule fois.
